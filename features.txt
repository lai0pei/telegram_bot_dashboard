## 22. BotFather Commands

### Bot creation and profile

- `/newbot` — Create a bot
- `/token` — Generate a new authentication token
- `/mybots` — Manage your bots
- `/setname` — Change the bot's name
- `/setdescription` — Change the description
- `/setabouttext` — Change the about text
- `/setuserpic` — Change the profile picture
- `/deletebot` — Delete a bot

### Commands and settings

- `/setcommands` — Configure bot commands
- `/setdomain` — Link a website domain
- `/setinline` — Enable or disable inline mode
- `/setinlinegeo` — Enable location-based inline results
- `/setinlinefeedback` — Configure inline feedback
- `/setjoingroups` — Control group access
- `/setprivacy` — Configure group privacy mode

### Games

- `/newgame` — Create a game
- `/listgames` — List games
- `/editgame` — Edit a game
- `/deletegame` — Delete a game

## 23. Essential Global Commands

- `/start` — Start interacting with the bot
- `/help` — Display help information and supported commands
- `/settings` — Display or modify user-specific settings
