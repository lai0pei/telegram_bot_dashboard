## 2. Main Telegram APIs

1. [Bot API](<https://core.telegram.org/bots >) — Create bots that interact with users through Telegram messages.
2. [Telegram API](<https://core.telegram.org/api >) — Build customized Telegram clients.
3. [TDLib](<https://core.telegram.org/tdlib >) — Develop cross-platform Telegram applications with networking, encryption, and local storage handled by the library.
4. [Gateway API](<https://core.telegram.org/gateway >) — Send verification codes through Telegram instead of SMS.
5. [Telegram Payments API](<https://core.telegram.org/bots/payments >) — Accept payments through Telegram bots.
6. [Telegram Widgets](<https://core.telegram.org/widgets >) — Embed Telegram features on websites.
